Step 1: Zotero Configuration

Connect Corall to your Zotero library to analyze your research interests.

Where to find your Zotero credentials:
1. Go to https://www.zotero.org/settings/keys
2. Click "Create new private key"
3. Give it a descriptive name and allow library access
4. Your User ID is shown in the URL bar (e.g., zotero.org/users/12345)

Step 2: Select Collection

Choose which Zotero collection to use for building your research profile.

Recommendation: Start with your entire library to build a comprehensive profile. You can always create more focused profiles later using specific collections.

Step 3: Recommendation Weights

Configure how Corall ranks paper recommendations. You can adjust these later.

How it works:
• Citation Weight: Prioritizes papers that cite your library
• Similarity Weight: Prioritizes papers with similar content to your library
• Total must sum to 1.0

Step 4: Initialize System

Ready to build your research profile! This will:

  • Fetch your Zotero library
  • Generate semantic embeddings for all papers
  • Build citation network from OpenAlex
  • Create cached profile for fast recommendations
Time estimate: This typically takes 5-15 minutes for ~200 papers. The system builds comprehensive caches so future searches are fast (1-3 minutes).
